All notable changes to ~tabularium~ are documented in this file.

* 0.4.3 (2026-04-06)

** Added

*** Plugin Interface for Entry Mode

- ~tabularium-entry-render-hook~ — hook run after form rendering with ~inhibit-read-only~ bound, allowing external packages to inject content (cross-table data, schema-specific hints, custom actions)
- ~tabularium-navigable~ text property — lines marked with this property participate in =TAB= / =S-TAB= navigation alongside schema fields, so plugin-injected content is keyboard-accessible
- ~tabularium-entry--all-nav-positions~ — unified navigator that merges field overlays and plugin-contributed navigable lines
- Hook fires after hint lines but before cursor positioning; plugins can read ~tabularium-entry--first-field-line~ and ~tabularium-entry--footer-start~ for layout context

** Fixed

*** Entry Buffer Rendering

- Symmetric 2-space left/right indent in the ornamental box display
- ~max-val-width~ set to 53 (80 − indent − label − separator − pad)
- Choices hint truncation rewritten: respects right padding, caps at 5 displayed choices with =…= overflow, and gracefully elides when the available column space is too narrow

* 0.4.2 (2026-03-18)

** Fixed

- Entry side window no longer stacks; =M-n= / =M-p= reuse the existing window via ~display-buffer-reuse-window~
- Byte compilation warnings resolved in =tabularium.el= and =tabularium-modeline.el= (unused variables, scoping bugs, wide docstrings, missing declarations)

** Changed

- Entry buffer inherits user's default cursor instead of forcing ~cursor-type~ (respects ~ryo-modal-mode~, ~evil-mode~, etc.)

* 0.4.1 (2026-03-17)

** Added

- ~tabularium-expunge-database~ (=X=) — permanently removes a database and deletes all associated files
- Multi-column sort via list of cons cells in view =:sort=
- View =:columns= list order now determines display column order

** Changed

- All visible-scoped functions renamed to ~tabularium-visible-*~
- ~tabularium-view-hard-refresh~ re-applies the active named view
- Registry paths normalized with ~abbreviate-file-name~ for cross-machine portability
- Section reorganization: Find/Replace and Math subsections split into Standard and Visible groups
- Default adjustments: page size 500, undo limit 100, max recent 100
- Tagline: "Structured data management in Emacs using SQL"

* 0.4.0 (2026-03-15)

** Added

- Fill-at-point commands (=F F=, =F f=, =F d=, =F x=, =F p=) — zero-prompt fill operations that infer column and value from context
- Layered filter system (=f= prefix) with AND/OR/NOT logic, exact-match (=f ==), and numeric comparison (=f #=)
- View-scoped replace (=R R=, =R ==, =R X=, =R Q=) — find/replace restricted to visible rows
- Side-window entry display (~tabularium-entry-display~ = ~side~)
- Long-field editing (=:long t=) with dedicated buffer and ~tabularium-long-edit-mode~
- Sort layer management (=s s= / =s d= / =s x= / =^=)
- Entry mode position restoration on submit
- View-scoped math (=# M=, =# D=, =# Q=)

** Changed

- Keybinding overhaul: sort =s= prefix, fill =F= prefix, filter =f= with layer semantics, =0= resets across subsystems, uppercase = visible scope, =@= suffix = across columns
- Entry display default changed to ~side~
- Filter infrastructure rewritten from single SQL string to layered plist model (~tabularium--filter-layers~)
- Fill infrastructure unified under ~tabularium--fill-execute~
- RFC 4180-compliant CSV/TSV parser for multiline field import/export
- Scroll position preservation across refresh and entry submit

** Fixed

- Entry submit scroll position (cursor no longer lands at buffer end)
- Multiline field handling in import/export
- ~tabularium-prompt-entry~ nil display and missing view refresh

** Removed

- Old multi-step sort/filter with =<CLEAR>= / =<DONE>= sentinels
- Redundant fill wrappers and line-level CSV parsers
- ~tabularium-long-mode~ (replaced by ~tabularium-long-edit-mode~)

* 0.3.0 (2026-03-03)

** Added

- Column operations (=|= prefix): copy, cut, paste, move, swap, insert, and column editor with undo support
- Smart fill without marks: auto-fills blanks from context
- Across-columns operations unified under =@= suffix
- Mark overlay improvements (explicit face, priority 100)
- Entry mode =S-TAB= fix via ~minibuffer-setup-hook~

** Changed

- Sentinels standardized to =<CAPS>= format
- =f @= for filter-across (was =a=), =# @= for count-across
- ~tabularium-schema-add-field~ consolidated into ~tabularium-view-column-add~

** Fixed

- Column editor scoping bug (~filled-ids~ in wrong ~let~ scope)
- Statistics buffer read-only error on second invocation
- Entry mode =S-TAB= conflict with ~outline-minor-mode~

* 0.2.0 (2026-02-04)

** Added

- Filter system for all field types with =<clear>= sentinel
- Export format selection (TSV/CSV) with overwrite confirmation
- Interactive multi-sort with per-column direction
- Smart fill dispatcher with automatic type detection
- Cell-jump navigation (=M-n= / =M-p= / =M-]= / =M-[=)
- Non-destructive paste (=V= / =A= keep kill ring by default)
- Schema command reorganization (=.= prefix)
- Goto operations (='= prefix)
- Completion system overhaul (historical, recent, vocabulary, related, filtered, function, union)
- Saved views with =:filter=, =:columns=, =:sort=, numeric presets
- Undo/redo for column and replace operations
- Entry mode unification and submit from minibuffer
- Freeze/unfreeze rows, query-replace, statistics functions
- Unicode box-drawing characters and modeline format

** Changed

- Keybinding updates across view, entry, and registry modes
- View reset (=0=) properly restores schema default sort
- Field selection via ~completing-read-multiple~

** Fixed

- Reindex system (ROWID-based, no more constraint violations)
- Summary mode format errors, import path handling
- Navigation bounds, registry path detection, entry buffer cleanup

* 0.1.0 (2026-01-26)

Initial release.

- SQLite-backed storage via Emacs 29.1+ built-in ~sqlite.el~
- Schema-driven field definitions with types, defaults, validation
- Multiple entry modes: form-based, minibuffer, quick entry
- Computed fields, CSV/TSV import/export, undo/redo
- Copy/paste, dired-style marking, multi-column sort
- Column visibility, reordering, fill down/series
- Historical completion, choice fields, date defaults
- Hydra and Transient menu support, modeline integration
- Registry for multiple databases, creation wizard
- PostgreSQL backend (optional, via emacsql)
