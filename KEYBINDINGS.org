#+TITLE: Default Keybindings
#+AUTHOR: Paul H. McClelland
#+OPTIONS: toc:1 num:nil

This file documents the default keybindings for ~tabularium~.  All bindings can be customized by modifying the relevant keymap (~tabularium-view-mode-map~, ~tabularium-entry-mode-map~, or ~tabularium-registry-mode-map~).

* View Mode (~tabularium-view-mode~)

** Navigation

| Key                  | Command                                         |
|----------------------+-------------------------------------------------|
| =n= / =p=                | Next / previous row                             |
| =TAB= / =S-TAB=          | Next / previous cell                            |
| ={= / =}=                | First / last row (same column)                  |
| =[= / =]=                | Line beginning / end                            |
| =M-n= / =M-p=            | Jump to different value ↓ / ↑                   |
| =M-<down>= / =M-<up>=    | Jump to different value ↓ / ↑                   |
| =M-]= / =M-[=            | Jump to different value → / ←                   |
| =M-<right>= / =M-<left>= | Jump to different value → / ←                   |
| =C-<down>= / =C-<up>=    | Page down / up (by ~tabularium-view-page-size~)   |
| =C-<right>= / =C-<left>= | Scroll viewport one column right / left        |
| =RET=                  | View entry details                              |
| =/=                    | Fuzzy find                                      |
| =g=                    | Refresh                                         |

Cell-jump navigation (=M-n=, =M-p=, =M-]=, =M-[=, and the =M-<arrow>= variants) moves to the next cell with a different value, useful for grouped or sorted data.  A prefix argument (e.g., =C-u 3 M-n=) jumps multiple value transitions.

Page navigation (=C-<down>= / =C-<up>=) jumps by the configured page size in either direction.  Column scroll (=C-<right>= / =C-<left>=) shifts the visible portion of the buffer one column at a time, useful when columns overflow the window.

** Replace (=R= prefix)

| Key | Command                               |
|-----+---------------------------------------|
| =R r= | Replace substring                     |
| =R R= | Replace substring (visible rows only) |
| =R e= | Replace exact                         |
| =R E= | Replace exact (visible rows only)     |
| =R p= | Replace pattern (SQL LIKE)            |
| =R x= | Replace regexp                        |
| =R X= | Replace regexp (visible rows only)    |
| =R /= | Query-replace (interactive)           |
| =R ?= | Query-replace (visible rows only)     |
| =R c= | Toggle case-sensitivity               |

Uppercase variants scope to visible rows only.  Lowercase variants act on marked rows (if any) or all rows.  Choice fields (those with =:choice= in the schema) are automatically excluded when the replacement value is not in the allowed set.

** Sort (=s= prefix)

| Key | Command                        |
|-----+--------------------------------|
| =^=   | Reverse sort                   |
| =s s= | Add sort layer                 |
| =s d= | Delete sort layer              |
| =s x= | Clear all sort (default order) |
| =s 0= | Clear all sort (same as =s x=)   |

Sort layers are additive: each =s s= adds a new column to the sort.  Already-sorted columns are excluded from the prompt.

** Fill (=F= prefix)

| Key | Command                                |
|-----+----------------------------------------|
| =F F= | Fill gap ↑ (value from above to point) |
| =F f= | Fill forward ↓ (value from point down) |
| =F n= | Fill next ↓ (prompted)                 |
| =F p= | Fill prev ↑ (prompted)                 |
| =F s= | Fill series (number or date)           |
| =F d= | Delete run (clear same-value cells)    |
| =F x= | Clear to row (prompted target)         |

=F F= and =F f= are zero-prompt: they infer the column and fill value from context.  =F n= and =F p= prompt for field and value.  =F d= clears the same-value run from point; =F x= clears to a prompted row ID.

Without marks, fill operations auto-detect blank ranges from point.  With marks, they fill marked rows (prompting before overwriting non-blank cells).

** Filter (=f= prefix)

| Key | Command                         |
|-----+---------------------------------|
| =f f= | Substring filter                |
| =f == | Exact match filter              |
| =f #= | Numeric comparison (> >= < <=)  |
| =f @= | Filter across columns           |
| =f d= | Delete filter layer             |
| =f s= | Toggle join logic (∧/∨/∧¬/∨¬)   |
| =f x= | Clear all filters               |
| =f 0= | Clear all filters (same as =f x=) |

Filters are progressive layers with logical operators.  The first filter sets the base layer; subsequent calls prompt for a join operator (AND, OR, AND NOT, OR NOT).  The modeline shows the filter stack: =(genre = Fiction) ∧ (price > 20) ∧¬ (status ~ inactive)=.

| Key   | Command                                  |
|-------+------------------------------------------|

| =z u= | Unfreeze row at point                    |

* Entry Mode (~tabularium-entry-mode~)

| =C-c C-n= / =C-c C-p= | Next / previous field |
| =n= / =p=             | Next / previous line  |
| =M-n= / =M-p=         | Next / previous entry |

** Field editing

| Key           | Command              |
|---------------+----------------------|
| =RET= / =C-c C-e= | Edit field at point  |
| === / =C-c C-d=   | Set field to default |
| =DEL= / =x=       | Clear field          |
| =C-c C-r=       | Reset field          |

Fields with ~:long t~ open a dedicated editing buffer instead of the minibuffer.  The default mode is ~tabularium-long-edit-mode~ (derived from ~text-mode~ with ~visual-line-mode~ and ~outline-minor-mode~).  Configurable via ~tabularium-long-field-mode~; window position via ~tabularium-long-field-display~ (~side~ or ~bottom~).
