* Roadmap

The following features are tentatively planned for future releases:

** v0.5.0

- [ ] Conditional Formatting
  - [ ] Row highlighting based on field values
  - [ ] Color-coded status indicators

- [ ] Field Validation
  - [ ] Reject invalid data on entry
  - [ ] Custom validation functions
  - [ ] Regex patterns for text fields

- [ ] ~time~ field type
  - [ ] Stored as ISO 8601 HH:MM[:SS]
  - [ ] Validation and default-to-now option

- [ ] Quick-startup wizard
  - [ ] One-shot prompt for all fields at once (e.g. =name:text:required age:integer date:date=)
  - [ ] Schema generation from a pasted header row

- [ ] Generate database from existing schema file
  - [ ] Build the =.db= file by reading a hand-written or imported =.schema.el=
  - [ ] Useful when the schema is moved between machines or restored from version control

- [ ] Face customization via ~defface~ / ~defcustom~
  - [ ] Tabulated-list header face
  - [ ] Marked-row face
  - [ ] Frozen-row face
  - [ ] Sort-indicator face
  - [ ] Filter / view-status face in the modeline
  - [ ] Group all under a ~tabularium-faces~ customize group

** v0.6.0

- [ ] Audit Log / Diff
  - [ ] Track all changes over time
  - [ ] View history for any entry
  - [ ] Compare versions

- [ ] Print/PDF Export
  - [ ] Formatted reports
  - [ ] Customizable templates
  - [ ] Page layout options

** Future

- [ ] Pivot Tables
  - [ ] Aggregate summaries
  - [ ] Cross-tabulation
  - [ ] Dynamic grouping

- [ ] Charts
  - [ ] Integration with gnuplot/GraphViz
  - [ ] SVG generation
  - [ ] Inline display in Emacs

- [ ] Linked Tables
  - [ ] Foreign key relationships
  - [ ] Relational queries
  - [ ] Cascading updates

- [ ] Additional Backends
  - [ ] MySQL (via ~emacsql~)
  - [ ] Remote database support
