* Roadmap

The following features are tentatively planned for future releases:

** v0.4.5

- [ ] SQL escaping in filter values
  - [ ] Route filter values through ~tabularium-db-sql-quote~
  - [ ] Honour ~tabularium-case-sensitive~ in substring filters

- [ ] Column clipboard symmetry
  - [ ] ~tabularium-view-column-paste-append~ to mirror ~tabularium-view-paste-append~ for rows
  - [ ] Bind to ~| A~ in keymap, hydra, and transient

- [ ] Computed field helper expansion
  - [ ] Add helpers for date arithmetic and lookup
  - [ ] Document patterns for cross-row aggregation in computed fields

** v0.5.0

- [ ] Conditional Formatting
  - [ ] Row highlighting based on field values
  - [ ] Color-coded status indicators

- [ ] Field Validation
  - [ ] Reject invalid data on entry
  - [ ] Custom validation functions
  - [ ] Regex patterns for text fields

** v0.6.0

- [ ] Audit Log / Diff
  - [ ] Track all changes over time
  - [ ] View history for any entry
  - [ ] Compare versions

- [ ] Print/PDF Export
  - [ ] Formatted reports
  - [ ] Customizable templates
  - [ ] Page layout options

** Future

- [ ] Pivot Tables
  - [ ] Aggregate summaries
  - [ ] Cross-tabulation
  - [ ] Dynamic grouping

- [ ] Charts
  - [ ] Integration with gnuplot/GraphViz
  - [ ] SVG generation
  - [ ] Inline display in Emacs

- [ ] Linked Tables
  - [ ] Foreign key relationships
  - [ ] Relational queries
  - [ ] Cascading updates

- [ ] Additional Backends
  - [ ] MySQL (via ~emacsql~)
  - [ ] Remote database support
