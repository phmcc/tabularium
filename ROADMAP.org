* Roadmap

The following features are tentatively planned for future releases:

** v0.4.7 — Plugin API maturation

- [ ] Field-changed hook (~tabularium-entry-field-changed-functions~) called when a field value is edited
- [ ] Schema-level header function (~:header-function~ schema property) so plugins do not need to install via ~tabularium-entry-pre-render-hook~

** v0.5.0

- [ ] Conditional Formatting
  - [ ] Row highlighting based on field values
  - [ ] Color-coded status indicators

- [ ] Field Validation
  - [ ] Reject invalid data on entry
  - [ ] Custom validation functions
  - [ ] Regex patterns for text fields

** v0.6.0

- [ ] Audit Log / Diff
  - [ ] Track all changes over time
  - [ ] View history for any entry
  - [ ] Compare versions

- [ ] Print/PDF Export
  - [ ] Formatted reports
  - [ ] Customizable templates
  - [ ] Page layout options

** Future

- [ ] Pivot Tables
  - [ ] Aggregate summaries
  - [ ] Cross-tabulation
  - [ ] Dynamic grouping

- [ ] Charts
  - [ ] Integration with gnuplot/GraphViz
  - [ ] SVG generation
  - [ ] Inline display in Emacs

- [ ] Linked Tables
  - [ ] Foreign key relationships
  - [ ] Relational queries
  - [ ] Cascading updates

- [ ] Additional Backends
  - [ ] MySQL (via ~emacsql~)
  - [ ] Remote database support
